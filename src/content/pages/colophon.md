Field Notes is intentionally simple, both to write for and to read. It runs
on **Tiny**, an editorial publishing theme for Astro.

- Built with [Astro](https://astro.build), statically generated with zero client-side frameworks
- Typeset in Geist Sans for long-form reading and Geist Mono for metadata and code
- Content authored in Markdown and processed via the extensible Sätteri pipeline
- Native Obsidian-compatible callouts, KaTeX math, and desktop source gutter
- Inbound backlink graph and multi-dimensional Browse taxonomy generated at build time
- Pure CSS lightbox and responsive gallery grids
- Publishes an [RSS feed](/rss.xml) and a standards-compliant XML sitemap
- Deployed as static files, requiring no Node server or database at runtime

If a page on this site feels slow, that's a bug — open an issue with
whoever's hosting the source.
