description: How this site is built.
---

Field Notes is intentionally simple, both to write for and to read.

- Built with [Astro](https://astro.build), generated fully at build time
- Content is Markdown and MDX, stored as plain files
- No client-side JavaScript framework — pages are static HTML
- Styling is a single small CSS file, no design system
- Publishes an [RSS feed](/rss.xml) and an XML sitemap
- Deployed as static files, no server required at runtime

If a page on this site feels slow, that's a bug — open an issue with
whoever's hosting the source.
